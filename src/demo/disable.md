你可以在页面的 frontmatter 中禁用主题功能。

## 禁用导航栏

```yaml
navbar: false
```

## 禁用侧边栏

```yaml
sidebar: false
```

## 禁用路径导航

```yaml
breadcrumb: false
```

## 禁用标题列表

```yaml
toc: false
```

## 禁用更新时间

```yaml
lastUpdated: false
```

## 禁用贡献者

```yaml
contributors: false
```

## 禁用编辑链接

```yaml
editLink: false
```

## 禁用返回顶部

```yaml
backToTop: false
```
