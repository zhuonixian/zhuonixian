# OpenAI

> 领先的 AI 研究与部署公司，GPT 系列和 ChatGPT 的创造者。

## 简介

OpenAI 于 2015 年由 Sam Altman、Elon Musk、Ilya Sutskever 等人共同创立，初始使命是确保通用人工智能（AGI）造福全人类。总部位于旧金山，是目前全球最具影响力的 AI 公司之一。

## 核心产品与模型

### GPT 系列

GPT 系列是 OpenAI 的旗舰产品线，从 [GPT-1](/posts/wiki/entities/gpt.html) 到 GPT-4o，每一代都在语言理解和生成能力上实现显著跃迁。ChatGPT（2022 年 12 月发布）标志着大语言模型走向大众，两个月内用户突破一亿。

### 多模态产品

- **DALL-E / DALL-E 3**：文本到图像生成模型，与 ChatGPT 深度集成
- **Sora**：文本到视频生成模型，在视频生成领域处于领先地位
- **Whisper**：开源语音识别模型，支持多语言转录

### API 平台

OpenAI API 是全球使用最广泛的 AI API 之一，提供 GPT-4、GPT-4o、Embeddings、DALL-E 等模型的访问接口，形成了庞大的开发者生态。

## 商业模式与合作

2019 年，OpenAI 从非营利组织转型为"有限营利"（capped-profit）公司。与 Microsoft 达成数十亿美元的战略合作，Microsoft 成为 OpenAI 的独家云服务提供商和主要投资者。

## 时间线

| 时间 | 事件 |
|------|------|
| 2015-12 | OpenAI 成立，定位非营利 AI 研究机构 |
| 2018 | 发布 GPT-1 |
| 2019 | 转型为有限营利公司，获 Microsoft 投资 |
| 2022-11 | ChatGPT 发布，引发全球 AI 热潮 |
| 2023-03 | GPT-4 发布，多模态能力亮相 |
| 2023-11 | 董事会事件，[Sam Altman](/posts/wiki/entities/sam-altman.html) 短暂被解雇后复职 |
| 2024-05 | GPT-4o 发布，实现实时多模态交互 |

## 争议与挑战

- 非营利到营利的转型引发使命偏移质疑
- 训练数据的版权争议
- 2023 年董事会治理危机暴露组织架构问题
- 对 AI 安全与商业化速度之间平衡的持续讨论
