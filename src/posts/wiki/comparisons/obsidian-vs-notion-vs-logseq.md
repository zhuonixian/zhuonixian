# Obsidian vs Notion vs Logseq

Obsidian、Notion 和 Logseq 是三款主流的个人知识管理工具，在核心理念和技术架构上有本质差异，适用于不同的使用场景。

## 定位差异

- **[Obsidian](/posts/wiki/entities/obsidian.html)**：本地优先的 Markdown 编辑器，基于文件系统的知识图谱。强调数据所有权和离线能力。
- **Notion**：云端数据库驱动的 All-in-One 工作空间。以 Block 和 Database 为核心，强调协作和可视化。
- **Logseq**：本地优先的大纲型笔记工具，以每日日志（Journal）为核心，天然支持双向链接。

## 核心功能对比

| 功能 | Obsidian | Notion | Logseq |
|------|----------|--------|--------|
| 编辑模式 | Markdown 原生 | Block 编辑器 | 大纲 / Markdown |
| 双向链接 | 核心特性，图谱可视化 | 支持但非核心 | 核心特性 |
| 数据库 | Dataview 插件实现 | 原生 Database | 查询语言实现 |
| 协作 | 需 Publish/Sync 插件 | 原生实时协作 | 有限 |
| 数据格式 | 纯 Markdown 文件 | 专有格式 | Markdown 文件 |

## 数据所有权

Obsidian 和 Logseq 数据以纯 Markdown 存储在本地，用户完全控制。Notion 数据存储在云端，迁移成本较高且依赖网络。

## 扩展性与选型

Obsidian 插件生态最丰富（2000+ 社区插件），Notion 通过 API 集成适合团队，Logseq 查询语言提供强大数据操作能力。重视数据自主权选 Obsidian，需要团队协作选 Notion，偏好日记流选 Logseq。三款工具都服务于 [知识管理](/posts/wiki/topics/knowledge-management.html) 的核心理念。
